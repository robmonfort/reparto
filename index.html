Pegar listado

Una parada por línea: Nombre; Dirección; 09:00-12:00; minutos. También sirve pegado desde Excel (columnas separadas por tab). Horario y minutos opcionales.

Google Maps (opcional)

Con una API key de Google (Geocoding API y Routes API activadas) las direcciones se ubican mejor y los horarios usan tránsito real. Sin key, la app usa datos libres y un factor de tránsito fijo. La key queda guardada solo en este dispositivo.
